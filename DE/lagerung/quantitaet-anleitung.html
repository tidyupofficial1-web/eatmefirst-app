🔢 Anzahl der gekauften Packungen

In dieses Feld tragen Sie einfach ein, wie viele Packungen, Schachteln oder ganze Kartons Sie gekauft haben und der Speisekammer hinzufügen möchten (unter Verwendung ganzer Zahlen: 1, 2, 3 usw.).

Praktische Beispiele:

• Sie haben 2 Packungen Nudeln gekauft? Geben Sie 2 ein.

• Sie haben einen Kasten/Tray Wasser mitgenommen? Geben Sie 1 ein (die Anzahl der enthaltenen Flaschen geben Sie in das Feld daneben Stücke pro Packung ein).

• Sie haben 3 Becher Joghurt gekauft? Geben Sie 3 ein.

💡 Einfacher Hinweis:
Verwenden Sie immer ganze Zahlen. Machen Sie sich keine Sorgen über Brüche oder Portionen: Das System kümmert sich um den restlichen Bestand, wenn das Produkt nach und nach verbraucht wird!
