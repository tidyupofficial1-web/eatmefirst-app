✍️ Beschreibung und Marktprodukte

Wenn Ihr Scan erfolgreich war, finden Sie hier bereits alles automatisch ausgefüllt. Aber was passiert, wenn der Code nicht erkannt wird, beschädigt ist oder es sich um Produkte handelt, die gar keinen Code haben?

Wie ich Ihnen bereits sagte, kommt es oft vor, dass eine Verpackung beschädigt oder nass ist oder dass der Code nicht in den Online-Datenbanken vorhanden ist (das passiert sogar an den Kassen im Supermarkt!). Oder denken Sie an all die frischen Waren, die Sie an Marktständen kaufen: Zwiebeln, Obst, Gemüse oder Käse von der Frischetheke – dort gibt es keinen Barcode!

💡 Keine Sorge, der Speicher Ihres PCs kümmert sich darum!

In all diesen Fällen tippen Sie einfach eine einfache Beschreibung ein (z. B. "Mürbegebäck 500g" oder "Gelbe Zwiebeln") und wählen die Kategorie aus.

Alle manuell eingegebenen Daten werden dauerhaft auf Ihrem Computer gespeichert. Wenn Sie das nächste Mal "Zwiebeln" in das Feld eingeben, schlägt Ihnen die App sofort die Einträge vor, die Sie zuvor erstellt hatten und die das Wort Zwiebeln enthielten: Ein einziger Klick auf den passenden neuen Posten (oder Sie erstellen einen neuen) genügt, und schon ist alles bereit – Sie müssen nur noch die Menge und das neue Verfallsdatum aktualisieren!

Einfacher geht's nicht!

(Und wenn der Scan kein Verpackungsbild finden konnte, machen Sie sich keine Sorgen: Das Bild ist nicht das Wichtigste, um den Überblick über Ihre Vorräte zu behalten!)
