📌 Kurzanleitung: Transparente und sichere Updates

So aktualisieren Sie die App, ohne etwas zu verlieren:
Wenn eine neue Version auf GitHub verfügbar ist, aktualisiert sich EatMeFirst und schützt Ihre Arbeit zu 100 %.

🔄 Der automatische Update-Prozess:

  • Präventive Speicherung: Vor jedem Update erstellt die App eine transparente Sicherungskopie Ihrer gesamten Datenbank.
  • Synchronisation: Lädt die neuen Dateien von GitHub herunter und lädt Ihre Produkte, Mengen und Verfallsdaten sofort wieder neu.
  • Möchten Sie zurückgehen? Wenn Sie mit der neuen Version nicht zufrieden sind, können Sie die vorherige Version wiederherstellen. Die App behält dabei auch alle neuen Produkte bei und integriert sie automatisch, die Sie während des Tests hinzugefügt hatten!
