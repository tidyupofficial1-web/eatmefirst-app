📌 Update-Anleitung: Wie Kontrolle und Datensicherheit funktionieren

EatMeFirst ist ein Programm, das nach einer Local-First-Philosophie entwickelt wurde: Die Daten Ihrer Speisekammer verbleiben vollständig auf Ihrem Gerät, und es gibt keine Verbindung zu externen Servern, die Sie ausspionieren oder kontaktieren. Aus diesem Grund haben Sie stets die vollständige Kontrolle über alle Neuerungen.

🚀 Wie Überprüfung und Aktualisierung ablaufen

  • Initiative des Nutzers: Da Sie lokal arbeiten, entscheiden Sie selbst, wann Sie über den entsprechenden Button nach neuen Funktionen oder Verbesserungen suchen möchten.
  • Automatisches präventives Backup: Bevor Änderungen heruntergeladen werden, erstellt das Programm eine Sicherungskopie Ihrer Datenbank direkt auf Ihrem Gerät. Ihre Daten verlassen niemals Ihren Kontrollbereich.
  • Reibungslose Installation: Wenn neue Funktionen verfügbar sind, die die Dateneingabe beschleunigen oder die Verwaltung verbessern, werden diese im Handumdrehen ohne technische Komplikationen integriert.

⏪ Was ist, wenn mir eine neue Version nicht gefällt? (Sicheres Rollback)

Seelenruhe steht an erster Stelle. Wenn Sie nach einem Update die vorige Version bevorzugen oder auf ein Problem stoßen:

  • Können Sie den Button Vorherige Version wiederherstellen im Hilfsmittel-Bereich verwenden.
  • Das System stellt die vorherige Version wieder her und behält alle Produkte und Änderungen bei, die Sie zwischenzeitlich hinzugefügt haben. Sie verlieren keinen einzigen Datensatz!
