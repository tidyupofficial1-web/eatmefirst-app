📌 Guía: Tareas Pendientes

Esta sección está pensada como un recordatorio dinámico para los recados que se deben realizar fuera de casa, especialmente útil cuando ya te encuentras fuera para hacer la compra u otros compromisos cotidianos.

En lugar de tareas o limpieza doméstica, utiliza esta lista para anotar rápidamente tareas como:

  • Ferretería: Hacer copias de llaves o comprar tornillería.
  • Librería / Papelería: Pasar a recoger libros escolares o material de oficina.
  • Farmacia: Comprar medicamentos prescritos o productos de parafarmacia.
  • Recados varios: Entrega o recogida de prendas en la tintorería, pagos o recogida de paquetes.

Cada elemento añadido se puede marcar una vez completado o eliminar definitivamente de la lista.
