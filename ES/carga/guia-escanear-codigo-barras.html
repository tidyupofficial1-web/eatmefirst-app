💬 El Escaneo y los Consejos de Leo para una Gestión Sencilla

La función de escaneo integrada transforma la cámara de tu smartphone en un práctico lector de códigos de barras (incluidos los códigos QR). Solo tienes que tocar el botón de escaneo y encuadrar el código del envase.

Tan pronto como la cámara enfoca los números del código de barras, la aplicación adquiere el código e inicia inmediatamente la búsqueda de los detalles del producto.

Cómo funciona en tu smartphone:
Todo se realiza directamente desde tu dispositivo móvil de forma rápida y sencilla, aprovechando la comodidad de la pantalla táctil y la portabilidad del teléfono para consultar la despensa, actualizar las fechas de caducidad y gestionar la lista de la compra estés donde estés en casa (en la cocina, en la despensa o cerca de la nevera).
⚠️ Consejos para la conexión y la seguridad de los datos:

1. Estabilidad de red: Asegúrate de tener una buena conexión Wi-Fi o datos móviles activos para permitir que la aplicación consulte rápidamente las bases de datos en línea durante el escaneo.

2. Autonomía, copias de seguridad seguras y envío por correo electrónico: La aplicación utiliza la memoria interna del navegador para almacenar tus datos de forma autónoma en el dispositivo. Sin embargo, para evitar cualquier riesgo en caso de pérdida o avería imprevista del teléfono, puedes elegir entre dos soluciones prácticas: conectar una memoria USB dedicada o enviar periódicamente la base de datos de copia de seguridad mediante un práctico mensaje de correo electrónico (e-mail). En el panel dedicado a las Utilidades, explicaremos paso a paso cómo realizar ambas operaciones de forma sencilla y segura.
🔒 Privacidad Blindada:
¡Todos los datos que introduces (descripción, cantidad, ubicación, caducidad) siguen siendo exclusivamente tuyos! El único intercambio con el exterior se refiere exclusivamente a la lectura del código de barras del envase para recuperar la información en línea.

¿Qué pasa después? Una vez leído el código, la aplicación consulta una base de datos abierta para recuperar automáticamente el nombre, la categoría, los ingredientes y la foto del producto. Si el producto está presente en el archivo, ¡la ficha se rellena sola!

¿Y la próxima vez? Si vuelves a escanear el mismo artículo, la aplicación recurrirá directamente a la memoria guardada en tu dispositivo: solo tendrás que actualizar la cantidad y la fecha de caducidad con un toque.

💡 ¿Y si el escaneo no encuentra el producto?
Si el código de barras no está presente en las bases de datos en línea, está dañado o pertenece a productos frescos del mercado (como fruta, verdura o quesos al corte), la aplicación te avisará inmediatamente. No hay problema: podrás introducir la descripción manualmente en un instante, como se explica en la guía dedicada al Nombre del Producto.
