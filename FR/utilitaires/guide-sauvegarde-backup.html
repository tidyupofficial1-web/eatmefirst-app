📌 Guide de Sauvegarde : Le conseil informatique de Leo !

Pourquoi parlons-nous de sauvegarde ?
EatMeFirst est conçu pour protéger à 100 % votre vie privée : vos données ne vont pas sur des serveurs distants, elles restent uniquement sur votre appareil. Mais précisément pour cette raison, si votre PC ou smartphone tombe en panne, votre garde-manger risque de disparaître avec lui !

🤓 Le coin de Leo : "Comment réagit votre navigateur ?"
Lorsque vous cliquez sur "Télécharger la sauvegarde", l'application génère un fichier au format .json. Par défaut, les navigateurs comme Chrome, Edge, Safari ou Firefox téléchargent les fichiers **automatiquement** dans le dossier par défaut du système (généralement le dossier Téléchargements).

💡 Deux astuces intelligentes pour enregistrer sur une clé USB :

  • Option 1 (Recommandée - L'astuce de l'administrateur système) :
    Rendez-vous dans les Paramètres de votre navigateur (Chrome/Edge/Firefox), cherchez la section Téléchargements et activez l'option "Toujours demander où enregistrer les fichiers avant de les télécharger". De cette façon, chaque fois que vous effectuerez une sauvegarde, la fenêtre de l'ordinateur s'ouvrira et vous pourrez sélectionner **directement votre clé USB** en un clic !
  • Option 2 (Double sécurité locale) :
    Si vous conservez les paramètres par défaut de votre navigateur, le fichier atterrira dans le dossier Téléchargements de votre ordinateur. Il vous suffira d'ouvrir ce dossier et de glisser-déposer le fichier sur la clé USB. Vous disposerez ainsi d'une **double copie de sauvegarde** : une sur le PC et une sur le support externe.

🔑 Le conseil final de Max :

Si vous utilisez EatMeFirst depuis l'ordinateur familial, laissez votre clé USB branchée en permanence pendant que vous travaillez. L'application effectue une sauvegarde automatique toutes les 5 minutes : en gardant le support connecté, vous vous assurez que la copie externe est toujours fraîche et mise à jour avec vos dernières modifications !
