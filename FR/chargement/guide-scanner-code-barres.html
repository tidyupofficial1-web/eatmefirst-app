💬 La Numérisation et les Conseils de Leo pour une Gestion Simple

La fonction de numérisation intégrée transforme l'appareil photo de votre smartphone en un lecteur pratique de codes-barres (y compris les codes QR). Il vous suffit d'appuyer sur le bouton de numérisation et de cadrer le code sur l'emballage.

Dès que l'appareil photo fait la mise au point sur les chiffres du code-barres, l'application capture le code et lance immédiatement la recherche des détails du produit.

Comment cela fonctionne sur votre smartphone :
Tout se fait directement depuis votre appareil mobile de manière rapide et immédiate, en profitant de la commodité de l'écran tactile et de la portabilité du téléphone pour consulter votre garde-manger, mettre à jour les dates de péremption et gérer votre liste de courses où que vous soyez dans la maison (dans la cuisine, le garde-manger ou devant le réfrigérateur).
⚠️ Conseils pour la connexion et la sécurité des données :

1. Stabilité du réseau : Assurez-vous d'avoir une bonne connexion Wi-Fi ou des données mobiles actives pour permettre à l'application d'interroger rapidement les bases de données en ligne pendant la numérisation.

2. Autonomie, sauvegardes sécurisées et envoi par e-mail : L'application utilise la mémoire interne du navigateur pour stocker vos données en toute autonomie sur l'appareil. Cependant, pour éviter tout risque en cas de perte ou de panne soudaine du téléphone, vous pouvez choisir entre deux solutions pratiques : connecter une clé USB dédiée ou envoyer périodiquement la base de données de sauvegarde via un message électronique (e-mail). Dans le panneau dédié aux Utilitaires, nous expliquerons étape par étape comment effectuer ces deux opérations simplement et en toute sécurité !
🔒 Confidentialité Blindée :
Toutes les données que vous saisissez (description, quantité, emplacement, dates de péremption) restent exclusivement les vôtres ! Le seul échange avec l'extérieur concerne uniquement la lecture du code-barres de l'emballage pour récupérer les informations en ligne.

Que se passe-t-il ensuite ? Une fois le code lu, l'application interroge une base de données ouverte pour récupérer automatiquement le nom, la catégorie, les ingrédients et la photo du produit. Si le produit est présent dans les archives, la fiche se remplit toute seule !

Et la fois suivante ? Si vous numérisez à nouveau le même article, l'application puisera directement dans la mémoire enregistrée sur votre appareil : il vous suffira de mettre à jour la quantité et la date de péremption d'une simple pression.

💡 Et si la numérisation ne trouve pas le produit ?
Si le code-barres ne figure pas dans les bases de données en ligne, s'il est abîmé ou s'il s'agit de produits frais du marché (comme les fruits, légumes ou fromages à la coupe), l'application vous le signalera immédiatement. Aucun problème : vous pourrez saisir la description manuellement en un instant, comme expliqué dans le guide dédié au Nom du Produit !
