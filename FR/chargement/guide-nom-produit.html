✍️ Description et Produits du Marché

Si vous avez effectué la numérisation et qu'elle a réussi, vous trouverez ici tout déjà rempli automatiquement. Mais que se passe-t-il si le code n'est pas reconnu, s'il est abîmé ou s'il s'agit de produits qui n'ont tout simplement pas de code ?

Comme je vous le disais tout à l'heure, il arrive souvent qu'un emballage soit abîmé, humide ou que le code ne figure pas dans les bases de données en ligne (cela arrive même aux caisses des supermarchés !). Ou pensez à tous ces produits frais que vous achetez sur les étals du marché : oignons, fruits, légumes ou le fromage pris au comptoir... là, il n'y a pas de code-barres !

💡 Pas de panique, la mémoire de votre PC s'en charge !

Dans tous ces cas, c'est vous qui rédigerez une description simple (par exemple « Biscuits Sablés 500g » ou « Oignons Jaunes ») et choisirez la catégorie.

Toutes les données que vous saisissez manuellement sont enregistrées pour toujours sur votre ordinateur. La prochaine fois que vous taperez « oignons » dans le champ, l'application vous proposera immédiatement les fiches que vous aviez déjà créées auparavant et comportant le terme oignons : il vous suffira d'un seul clic sur celle qui correspond au nouvel arrivage ou d'en créer une nouvelle, et tout sera de nouveau prêt. Vous n'aurez plus qu'à actualiser la quantité et la nouvelle date de péremption !

Plus simple, tu meurs !

(Et si la numérisation n'a pas trouvé l'image de l'emballage, ne vous inquiétez pas : l'image n'est pas l'élément le plus important pour garder une trace de ce que vous avez dans votre garde-manger !)
