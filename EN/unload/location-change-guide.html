Product Location Change 📍
Eva's guide to organizing space

When you take away part of a product (for example, a single bottle from a large pack), the remainder certainly won't stay in the same place and will have a new destination.


If you use it up right away, it won't have any destination because it will go straight to the shopping list. If instead you reduce it, choose a location from the ones you've used before or type a new destination: we'll save it so you can reuse it next time too!
