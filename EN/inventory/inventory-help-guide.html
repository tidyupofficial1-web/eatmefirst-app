How to search and filter products in inventory

To help you quickly check your home food supplies, the inventory provides three different search and filter options:

🔍 1. Quick Search by Name or Keyword
Type the item name into the search box (e.g. "milk" or "tomato sauce") to filter the list instantly.
📍 2. Filter by Home Storage Location
Select a specific location from the dropdown menu (e.g. "Refrigerator" or "Freezer") to view only items stored in that area.
📂 3. Filter by Food Category
Filter by grocery type (e.g. "Dairy" or "Canned Goods") to see how many items of a specific category remain.
💡 Handy Tip:
You can combine filters (for example, selecting the location "Refrigerator" and category "Dairy") for a highly specific search!
