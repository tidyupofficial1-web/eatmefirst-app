📌 Updates Guide: How checks and data security work

EatMeFirst is a program designed with a local-first philosophy: your pantry data resides entirely on your device, and there is no connection to external servers spying on you or contacting you. For this reason, you always have complete control over new features.

🚀 How checking and updating take place

  • User Initiative: Since you work locally, you decide when to check for new features or improvements using the dedicated button.
  • Automatic Preventive Backup: Before downloading any modifications, the program creates a secure backup copy of your database directly on your device. Your data never leaves your control.
  • Smooth Installation: If new features are available that speed up entry or improve management, they are integrated in a flash without any technical complications for you.

⏪ What if a new version doesn't convince me? (Secure Rollback)

Peace of mind comes first. If after an update you prefer the previous version or encounter any issues:

  • You can use the Restore previous version button in the Utilities section.
  • The system will restore the previous version while keeping all products and changes you added in the meantime intact. You won't lose a single piece of data!
