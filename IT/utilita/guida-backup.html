📌 Guida al Backup: La sicurezza dei tuoi dati!

Perché parliamo di backup?
EatMeFirst tutela al 100% la tua privacy lavorando in modalità Local-First: i dati risiedono protetti nel tuo dispositivo. Per evitare di perdere la dispensa in caso di guasti hardware, l'app gestisce la sicurezza in modo automatico su PC e facilitato su smartphone.

🤓 Il file di salvataggio (eatme_backup.json):
Tutto il tuo inventario è racchiuso in un unico file di dati chiamato eatme_backup.json. Viene gestito dal browser per garantire che la tua dispensa sia sempre al sicuro e pronta al ripristino.

💾 Come funziona la protezione nei due casi:

  • 1. Su PC con Chiavetta USB (Salvataggio automatico in tempo reale):
    Tenendo la chiavetta USB inserita nel computer mentre usi il programma, ogni singola modifica viene salvata all'istante e in tempo reale sia nella memoria del PC che sulla chiavetta. Non devi ricordarti di cliccare nulla: la scrittura è simultanea e automatica.
  • 2. Su Smartphone (Invio periodico tramite E-mail):
    Poiché sul cellulare non è pratico mantenere una chiavetta USB sempre collegata, i dati vengono salvati in tempo reale sulla memoria del telefono. Per avere una copia di sicurezza esterna, il metodo più semplice è esportare il file eatme_backup.json inviandolo a te stesso tramite e-mail.
    Il consiglio furbo: fai l'invio via e-mail ogni 10-15 movimenti importanti. In questo modo, se il telefono dovesse rompersi o smarrirsi, al massimo perderai solo le ultimissime modifiche.

⚙️ Come indirizzare il file manualmente (se serve):

Se sul PC desideri scaricare una copia manuale del file eatme_backup.json scegliendo la cartella o la chiavetta di destinazione, puoi attivare questa opzione nel tuo browser:

  • Google Chrome / Microsoft Edge: Impostazioni → Download → Attiva "Chiedi dove salvare ciascun file prima del download".
  • Mozilla Firefox: Impostazioni → Generale → File e applicazioni → Spunta "Chiedi sempre dove salvare i file".
